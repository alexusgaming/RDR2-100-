# RDR2 на 100%

Неофициальный помощник по Red Dead Redemption 2: достижения по главам, 90 испытаний, чек-лист «Зоолога» и карта меток. Работает как приложение на телефоне и компьютере, в том числе без интернета.

## Что в папке

- `index.html` — само приложение.
- `manifest.webmanifest` — название, цвета и иконки для установки.
- `sw.js` — офлайн-режим: после первого открытия приложение работает без сети.
- `favicon.svg` и папка `icons/` — иконка во всех нужных размерах.

Файлы должны лежать вместе, как в архиве. Переименовывать их не нужно.

## Шаг 1. Выложить в интернет (один раз)

Установка работает только с сайта по адресу `https://…`. Открыть `index.html` двойным щелчком можно, но установить так не получится.

### Вариант А — Netlify Drop (быстрее всего)

1. Распакуйте архив.
2. Откройте https://app.netlify.com/drop и перетащите туда папку `rdr2-100` целиком.
3. Через несколько секунд появится ссылка на сайт.
4. Зарегистрируйтесь в Netlify (бесплатно) и нажмите «Claim», чтобы сайт остался навсегда. Без этого он удалится сам.

### Вариант Б — GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `rdr2-100`.
2. Нажмите «Add file → Upload files» и загрузите **содержимое** папки (`index.html`, `sw.js`, `icons/` и остальное), а не саму папку.
3. Откройте «Settings → Pages», в «Build and deployment» выберите «Deploy from a branch», ветку `main` и папку `/ (root)`, сохраните.
4. Через минуту-две сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/rdr2-100/`.

## Шаг 2. Установить на телефон

- **Android (Chrome):** откройте ссылку, затем меню «⋮» → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** откройте ссылку, затем «Поделиться» → «На экран „Домой“».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке.

На экране появится иконка с латунной печатью «100», приложение откроется без адресной строки.

## Как отправить другим

Просто отправьте ссылку на сайт. Аккаунт не нужен: каждый ставит приложение себе, и у каждого свой прогресс.

## Где хранится прогресс

На устройстве, в браузере. Чтобы перенести прогресс на другой телефон или из версии в Claude, откройте внизу «Настройки → Перенос прогресса», нажмите «Скопировать код» и вставьте код на другом устройстве.

Если очистить данные браузера или удалить приложение, прогресс пропадёт. Перед этим скопируйте код.

## Как обновить приложение

Замените файлы на сайте новыми и в `sw.js` поменяйте строку `rdr2-100-v1` на `rdr2-100-v2` (и так далее). У пользователей обновление подтянется при следующем открытии с интернетом.
